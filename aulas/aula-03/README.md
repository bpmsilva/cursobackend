# Fundamentos do PHP

Esta Seção/Aula traz conteúdo teórico, com o objetivo de apresentar os fundamentos da linguagem PHP. Aqui se discutem as estruturas para controle de fluxo (como `if`, `else`, `switch`), estruturas de repetição (como `for`, `while`, `foreach`) e funções. A temática de funções é profundamente abordada em níveis introdutório, intermediário e avançado. Caso você ache o conteúdo muito denso, recomendo que você estude o conteúdo introdutório de funções, e depois retorne para estudar o conteúdo intermediário e avançado.
